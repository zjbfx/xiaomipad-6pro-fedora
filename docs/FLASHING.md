# 安装指南

## 安装包

本项目不发布预编译安装包。按 [Fedora 说明](FEDORA.zh-CN.md) 在 Fedora 主机上构建后，
下载或使用同一版本的全部安装文件，按照[安装步骤](INSTALL-TESTING.md)执行。
系统归档可能分为多个文件，指南提供合并命令；不要混用版本。

## 适用设备

Xiaomi Pad 6 Pro，代号 `liuqin`，芯片 SM8475。其他小米平板型号不兼容。
首次安装和首启验证在 **256 GB 机型**上完成；本项目的 128 GB 与 512 GB 容量变体按下方规则放行，
但未逐一真机验证；自定义分区布局不支持。不得修改常量或跳过检查来强行安装。

程序要求 Bootloader 已解锁；出厂分区表上的首次安装要求 A 槽活动（出厂状态），
并在设备侧核对以下 Linux sysfs 数值（容量单位为 512 字节扇区，不是文件系统块大小）：

| 项目 | 允许值 |
|---|---|
| userdata 分区名（PARTNAME） | `userdata`，且唯一、位于第一颗 UFS（sda） |
| sda 逻辑块大小 | 4096 |
| userdata 扇区数 | ≥ 33554432（16 GiB） |

分区编号与起始偏移随容量变体不同，不属于身份检查；安装器与启动链均按
PARTNAME 解析目标分区。型号、槽位或会话身份无法确认时，安装器必须停止，
不允许猜测后继续写入。这些检查用于减少误操作风险，并不构成不会损坏设备的保证。

## 数据与恢复

本项目只安装 Linux：`userdata` 分区被删除，其空间交给 `linux_root` 与 `linux_home`。
首次安装会清除数据，解锁 Bootloader 也会清除用户数据。

安装前需要：

1. 将个人文件备份到平板以外的位置。
2. 准备与设备匹配的原厂固件，并保留对应恢复说明。
   上游验证基线是 HyperOS OS2.0.6.0；本机为 OS3，刷入低于设备已熔断版本的固件会使平板变砖。
3. 在覆盖任何 boot 分区前，备份原 boot 分区与出厂 `persist` 分区。
   RAM 临时启动与持久刷写是不同操作；刷写后再备份不能保留原镜像。

安装器必须从这台平板读取出厂校准与设备地址，不可使用其他平板的 `persist`
镜像或校准数据。

恢复 Android 需要还原适配的原厂固件，并为 Android 重新准备 userdata。
仅替换 boot 镜像不能撤销 Linux 安装，也不会恢复分区表。设备上仍有非原厂启动镜像时，应保持
Bootloader 解锁。

## 发布内容

一个安装包包含匹配的 boot 镜像与根文件系统、安装工具、校验文件、源码版本、
支持的存储布局和恢复要求。安装器会在访问设备前校验镜像。
单独编译出的内核文件不是完整安装镜像。
